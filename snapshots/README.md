# PawDex — wireframe directions (for Claude Code)

PawDex is a cozy "pokedex for cats" mobile web app: log neighbourhood cats with photo, name, personality traits (like pokemon types), location spotted, story/notes, and sighting count/dates. Themeable palettes. NOT game-y — cozy journal vibe. Each PNG shows 3 screens: Dex (collection), Cat detail, New Cat form.

- 1a-sticker-book.png — Cute sticker-book: rotated sticker cards, hard offset shadows, 2px ink borders, collectible trait chips, wobbly blob photo frame on the New Cat screen.
- 1b-field-guide.png — Vintage naturalist encyclopedia: serif + small-caps labels, numbered specimens (No. 001), fake-latin species names, roman-numeral sighting tallies, framed "specimen plates", ledger-style form.
- 1c-scrapbook-journal.png — Scrapbook diary: ruled-paper background, polaroids with washi tape, handwritten font, dex doubles as a chronological diary feed of sightings.
- 1d-cozy-dexgadget.png — Soft handheld device chrome around the whole app (lens, d-pad, buttons); one big entry at a time with prev/next; paw-print sighting tally; "not yet spotted" dashed slots; themes recolor the device shell.
- 1e-cat-passport.png — Passport metaphor: dex is a grid of round ink stamps (dashed circle = empty slot), each cat is a "visa page" with dated entry stamps per sighting and a faint REGULAR rubber stamp.

Also included: the source wireframe HTML (PawDex-Wireframes.html) — the real markup with all styles inline.
